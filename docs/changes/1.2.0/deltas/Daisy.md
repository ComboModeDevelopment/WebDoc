# Daisy — 1.2.0

## Changes since 1.1.0

### Jab / Tilts

**Jab 3 (alt variant)**
added 1.1x startup frame speed modifier
removed 0.3x slow-mo window during startup
endlag frame speed modifier: 1.3x → 1.8x

**Up Tilt**
reworked from multi-hit into single strong hit
startup frame speed modifier: 1.2x → 1.8x
new hitboxes: damage 11, trajectory 75, kbg 68, bkb 60 (4 hitboxes on bones 0x48/0x50)

### Smash Attacks

**Forward Smash**
startup timers shortened (3 → 2, 4 → 3 frames)
added extra late hitbox: damage 22, trajectory 41, hitlag multiplier 2

### Special Moves

**Down B (Turnip Pull)**
turnip pull hitbox active duration: 3 → 8 frames
turnip pull hitbox size: 7 → 8
pull timers: 3 → 1, 7 → 8

**Side B / Aerial Turnip Throw**
throw hit trajectory: 55 → 70
added edge-slide state during throw

**Up B**
main hit damage: 17 → 20
main hit kbg: 133 → 80
main hit bkb: 10 → 50
main hit hitlag multiplier: 1 → 2
added 0.5x startup FSM followed by 1.2x FSM (dramatic pause)
removed final low-damage multi-hit pass
