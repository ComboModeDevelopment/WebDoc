# Zero Suit Samus — 1.0.0

## Changes since 0.9.5

### Jab / Tilts

**Jab**
can now cancel jab 2 into attacks

**Forward Tilt**
sped up 1.4x

**Up Tilt**
improved hitboxes and sped up endlag 1.2x

### Aerial Attacks

**Neutral Air**
new nair

**Forward Air**
given new properties vs ground and air opponents to help the move connect better

**Back Air**
damage: 15 → 16

**Up Air**
slowed during attack to make sure hitboxes track the move better

**Down Air**
no more skb on grounded hit to prevent infinite

### Special Moves

**Neutral B**
startup sped up 2x
damage: 4/6 → 6/8

**Side B**
removed speed up on move

**Down B**
in air, now goes straight up

### Other

**Dash Attack**
buffed hitbox sizes
