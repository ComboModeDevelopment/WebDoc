# Lucario — 0.8.0

## Changes since 0.7.0

### Jab / Tilts

**Jab**
startup sped up 1.3x

**Forward Tilt**
startup sped up 1.2x
can cancel first hit into specials if it connects

**Up Tilt**
iasa: 33 → 27

**Down Tilt**
iasa: 25 → 21
angle: 71 → 77

### Smash Attacks

**Forward Smash**
startup sped up: 1.2x → 2.2x, then slowed: 2.2x → 1.6x net

**Up Smash**
removed sourspot

### Special Moves

**Side B**
increased size and duration of grab hitboxes
the move is no longer roll canceled, now pressing a or using the c stick will cancel the grab into an f smash if done before the throw
can now grab aerial opponents with the move, using it in the air will make the angle 361 and have higher knockback
grounded side b damage reduced
grounded side b now has a low knockback hitbox that appears right before the grab, making it possible to grab people off the ground from a missed tech

**Up B**
startup sped up 1.2x
can now wall jump out of up b
now has a hitbox

### Other

**Dash Attack**
sweetspot angle: 75 → 70
late hit angle: 120 → 70

**Grab**
active frames: 2 → 4

**Up Throw**
bkb: 70 → 110
kbg: 80 → 20
