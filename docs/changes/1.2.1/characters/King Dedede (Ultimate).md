# King Dedede (Ultimate) — 1.2.1

## Changes

### Jab / Tilts

**Forward Tilt**
removed startup speedup (1.4x)
endlag slowed (1.2x speed → 0.9x)

**Down Tilt**
spike hitboxes (damage 12, angle 275) now only hit grounded opponents
added aerial-only hitboxes on the first hit (damage 11, angle 55, kbg 75, bkb 60) — no longer spikes aerial opponents

### Aerial Attacks

**Forward Air**
added startup slowdown (0.25x speed for a few frames before the hit)
added endlag slowdown (0.8x)

### Other

Animations adjusted to give him much more range like normal Dedede
