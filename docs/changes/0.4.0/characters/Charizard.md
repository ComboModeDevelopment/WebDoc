# Charizard — 0.4.0

## Changes

### Jab / Tilts

**Jab**
jab 1, 2, 3 all link better (angles on hit 1+2 all changed to 80)
jab 3 angles (45, 50, 60, 75) all changed to 80

### Aerial Attacks

**Neutral Air**
sped up 1.2x

**Back Air**
first hit angle: 270 → 365
removed multihit, gave first hit damage to 2nd hit
damage: 7/9 → 12/14
kbg: 130 → 100

**Down Air**
vs grounded opponents now meteors (angle: 70 → 270)

**Up Air**
iasa: 47 → 39
angle: 85 → 80

### Smash Attacks

**Forward Smash**
first hit all angles changed to 270 → 365 (hits connect much better)
removed multihit, gave the initial hits damage to the final hit
damage: 17 → 22

**Down Smash**
angle: 70 → 30
kbg: 75 → 85

**Up Smash**
iasa: 47 → 40
2nd hit frames: 14-18 → 12-20 (makes hits link much better)

### Special Moves
