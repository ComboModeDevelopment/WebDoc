# Stage icons (Credits > Stages)

Icons for the stage credits grid, named by slug:

```
images/stages/<slug>.png
```

The slug comes from the stage name in `scripts/credits/stages.txt`
(e.g. `Final Destination:` -> `final-destination.png`). Missing icons fall back
to a text tile. Recommended: roughly square, transparent PNGs (shown at 56x56).
