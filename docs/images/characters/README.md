# Character icons (Quirks grid)

The Quirks section shows a clickable grid of characters. Each tile uses an icon
image from this folder, named after the character's slug:

```
images/characters/<slug>.png
```

Any tile whose `.png` is missing simply shows a text-only tile instead, so you
can add art gradually — nothing breaks in the meantime.

Recommended: roughly square, transparent PNGs (they're displayed at 56×56).

The slugs are generated from `scripts/quirks_source.txt` (see the `icon` field
in `docs/data/quirks.json`). Current expected filenames:
