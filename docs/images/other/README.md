# Other icons (Credits > Other)

Icons for the "other" credits grid (music, code, UI, etc.), named by slug:

```
images/other/<slug>.png
```

The slug comes from the entry name in `scripts/credits/other.txt`
(e.g. `Music:` -> `music.png`). Missing icons fall back to a text tile.
Recommended: roughly square, transparent PNGs (shown at 56x56).
