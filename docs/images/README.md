# Images

## Logo

The hero section uses the Combo Mode logo. Save it here as:

- `logo.png`

Tips:

- Use a **transparent** background (PNG with alpha) so it looks right in both
  light and dark mode. A logo saved on a solid white box will show that box on
  the dark theme.
- Any reasonable resolution works; the hero scales it down to fit
  (`width: min(640px, 90%)`), so an image around 1000–1600px wide is plenty.

Until `logo.png` is present, the hero falls back to showing the text
"Combo Mode" (the image's `alt` text).
